Based on the HTML alone, this looks like a **hand-crafted static website built on top of Bootstrap 5**, rather than something generated by a typical static site generator such as Hugo, Jekyll, MkDocs, or WordPress.

Some clues:

### What we can tell with confidence

#### Bootstrap 5

The page explicitly loads Bootstrap components:

```html
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.2.3/dist/js/bootstrap.bundle.min.js"></script>
```

and uses Bootstrap classes throughout:

```html
navbar navbar-expand-lg navbar-dark bg-dark
container px-5
row gx-5
card mb-5
col-lg-6 col-xl-6
```

So the layout is definitely Bootstrap 5.

#### Bootstrap Icons

It loads:

```html
https://cdn.jsdelivr.net/npm/bootstrap-icons@1.4.1/font/bootstrap-icons.css
```

which provides icons like:

```html
<i class="bi bi-envelope"></i>
```

### Strong clue: Start Bootstrap template

The structure strongly resembles the free **Business Frontpage** template from the company Start Bootstrap.

Examples:

```html
<header class="bg-dark py-5">
<section class="py-5 border-bottom">
<div class="container px-5 my-5">
<div class="text-center mb-5">
```

These patterns are almost identical to several Start Bootstrap starter templates.

My guess is:

1. Started from a Start Bootstrap template.
2. Customized heavily by Stéphane.
3. Served as plain static HTML.
