# 1. Identity + scope

Defines what this archive *is*

```
archive:
  name: "repository"
  role: "root"
  type: ["archive", "collection"]
```

------

# 2. Structural contract

Defines allowed architecture patterns

```
structure:
  languages:
    - en
    - fr

  layers:
    - archives
    - collections
    - entities
    - content
```

------

# 3. Entity model (your semantic container rules)

Defines what an “entity” means everywhere

```
entity:
  index_file: "index.md"
  folders:
    assets: "assets"
    meta: "meta"
```

# 4. Inheritance rules (very important in your model)

Defines how sub-archives behave

```
inheritance:
  mode: "strict"
  overrides_allowed: false
```

or more flexible:

```
inheritance:
  mode: "hierarchical"
  overrides_allowed: true
```
